# FLOAURA — E-commerce UI Demo

A static, responsive multi-page storefront concept built with HTML, CSS and vanilla JavaScript.

## Run locally
Open `index.html` with VS Code Live Server, or open it directly in a browser.

## Pages
- `index.html` — Home
- `pages/shop.html` — Product catalogue and category filters
- `pages/product.html?id=p1` — Product detail
- `pages/cart.html` — Empty shopping bag preview
- `pages/checkout.html` — Checkout layout preview

## Important demo boundaries
- No backend, database, user accounts, cart persistence, order submission or payment gateway.
- Product prices are illustrative placeholders and must be confirmed by FLOAURA.
- Delivery messaging is limited to Pune, as specified by the client.
- Product photographs supplied for this demo are stored locally in `images/`.

## Before production
Confirm final product names, prices, stock/availability, delivery zones and policies with the client. Then scope the production build separately.
